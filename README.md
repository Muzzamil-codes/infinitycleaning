# Infinity Cleaning

A Next.js website for a pest control and cleaning service business.

## Conversion Rate Improvements

The website has been optimized for higher conversion rates with the following enhancements:

### 1. Clear Headline
- Added a concise headline that clearly states the service offering
- Positioned for maximum visibility on the hero section

### 2. Strong Call-to-Action (CTA)
- Updated CTAs with action-oriented text ("Get a Free Quote", "Schedule an Inspection")
- Added hover animations to increase engagement
- Implemented a floating CTA button that follows users as they scroll

### 3. Trust Elements
- Enhanced testimonials with customer images
- Added before/after treatment images
- Included certification badges
- Implemented subtle animations to draw attention to trust signals

### 4. Benefit Highlighting
- Used checkmark bullet points for key benefits
- Added specific benefit lists to each service card
- Emphasized 24/7 service, eco-friendly products, and professional expertise

### 5. Mobile Optimization
- Improved mobile navigation
- Ensured all animations work smoothly on mobile devices
- Optimized layout for mobile-first browsing

## Required Images

To fully implement the design, the following image assets are needed:

### Testimonial Images
- `/customer1.jpg`
- `/customer2.jpg`
- `/customer3.jpg`

### Before/After Images
- `/before1.jpg`
- `/after1.jpg`
- `/before2.jpg`
- `/after2.jpg`

### Certification Images
- `/eco-cert.png`
- `/cleaning-cert.png`
- `/pest-cert.png`

Place these images in the `/public` directory to ensure they are properly displayed.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
